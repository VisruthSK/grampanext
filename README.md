# grampanext

`grampanext` is a Chrome and Firefox extension that toggles inline highlights for [Grampan](https://github.com/stephenturner/grampan) matches on the current article. 

The detector code in `src/grampan-engine.js` is copied from Grampan commit `300cdab52a6451e3eee3dae62a5911333e6a3ee8`. See `NOTICE` and `LICENSE` for the Apache-2.0 attribution and license.

Run tests with `npm test`, and build locally with `npm build`.
